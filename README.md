# GearNest - Equipment Rental Platform

## Purpose
Owner ra equipment list korbe, Customer ra browse kore book korbe, Stripe diye secure payment korbe.

## Live URL
Client: https://gearnest-client.vercel.app
Server: https://gearnest-server.onrender.com

## Key Features
- JWT Auth + Google Login + Role - Customer / Owner / Admin
- Featured Equipment - Approved 6 ta
- Categories, Why Choose Us, Reviews, How It Works
- Equipment Details + Favorites DB + Booking Modal + Stripe Payment
- All Equipment - Search by Name / Location, Filter Category / Rental Type / Price / Availability, Sort Low / High / New, Pagination
- Customer Dashboard - My Rentals Table, Favorites Table, Profile Update
- Owner Dashboard - Add Equipment, My Equipment, My Rentals, Analytics Chart
- Admin Dashboard - All Users Role Change, All Equipment Approve / Reject, All Rentals, Analytics Chart
- Theme Toggle Dark / Light + LocalStorage, Loading / Error Page, Cron Job, Email Notification
